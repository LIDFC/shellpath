# Как добавить уровень

## 1. Придумайте, чему учит уровень

Одна идея на уровень. Проверьте, что всё нужное для решения уже объяснено на предыдущих уровнях. Если нет — сначала нужен уровень, который это объясняет. Например, блок SSH требует `chmod`, поэтому права объясняются в «Начальном» на уровне 12.

## 2. Добавьте объект в массив блока

Уровни лежат в `src/levels/basic.js`, `net.js`, `ssh.js`. Номер уровня — позиция в массиве. Новый уровень обычно вставляют перед финалом блока.

### Начальный блок и SSH

```js
{
  title: 'Короткое название',
  goal: 'Задание в **Markdown**. `код` — моноширинным.\n\nНовый абзац — пустая строка.',
  commands: ['grep', 'sort'],          // кнопки-подсказки; у каждой должна быть справка в T.man
  hint: 'Готовая команда: `sort data.txt | uniq -u`',
  host: 'shellpath',                   // только в SSH: куда попадает игрок, выбрав уровень
  build: () => {
    // Файлы уровня. Пароль следующего уровня — PW[n + 1] (src/worlds/base.js).
    put('/home/level16/data.txt', F('…', 'level17', 'level16', 0o640));
  },
  solve: async (t) => {
    // Эталонное решение. t.run(команда, [ответы на вопросы]).
    await t.run('sort data.txt | uniq -u');
  },
},
```

Тест для «Начального» блока проверяет, что после `solve` в выводе есть пароль следующего уровня. Для SSH — что игрок оказался под пользователем `key{n+1}`.

### Блок «Сеть»

```js
{
  title: '…',
  host: 'hq-rtr',                       // машина лаборатории, где игрок — root
  readme: 'Текст для /root/readme',
  setup: () => {
    // Лаборатория собирается полностью рабочей (src/worlds/lab-world.js). Сломайте нужное:
    const h = LAB.hosts['hq-rtr'];
    deleteIn(h.fs, '/etc/net/ifaces/gre1/ipv4route');
    bootHost(h);                         // применить изменённые файлы
  },
  goal: '…', commands: ['…'], hint: '…',
  check: async (h) => {
    // Вызывается командой labcheck. Печатайте результат через ck(ok, 'что проверили').
    rebootFor('hq-rtr');                 // если настройки должны пережить перезагрузку
    return ck(pingOK('hq-srv', '192.168.200.2'), 'hq-srv → филиал');
  },
  solve: async (t) => {
    await t.run('…');
    await t.run('labcheck', ['n']);      // 'n' — не переходить на следующий уровень
  },
},
```

## 3. Обновите число уровней

В `src/core/state.js` у блока есть `max` — номер последнего уровня. Увеличьте его. Тест «число уровней совпадает с BLOCKS» напомнит, если забудете.

## 4. Нужна своя команда?

Если команда нужна только одному уровню (как `gatekeeper` или `harden-check`), зарегистрируйте её в том же файле уровня:

```js
register('mycheck', (args, ctx) => ({ out: 'текст\n' }));
```

И добавьте справку в `T.man` в `src/i18n/ru.js`. Если у команды есть аргументы, которые стоит дополнять по Tab, опишите их:

```js
registerCompleter('mycheck', (args, cur) => (args.length ? [] : ['--fix', '--verbose']));
```

## 5. Проверьте

```sh
npm test
npm start   # и пройдите уровень руками
```

## Советы

- Подсказка даёт готовую команду. Задание объясняет, почему она работает.
- Ошибки команд — по-английски, как в Linux. Если ошибку легко не понять, добавьте `note` с объяснением по-русски.
- Не делайте уровни, которые проходятся одним Tab: дополнение не подставляет имена с пробелами и спецсимволами без кавычек.
