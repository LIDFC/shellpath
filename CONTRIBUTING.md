# Как помочь проекту

Спасибо, что заглянули. Больше всего проекту нужны новые уровни, сообщения о том, где эмулятор ведёт себя не как настоящий Linux, и правки текстов.

## Быстрый старт

```sh
git clone https://github.com/<ваш-аккаунт>/shellpath.git
cd shellpath
npm test      # должно быть «fail 0»
npm start     # http://localhost:8080
```

Зависимостей нет: только Node.js 20+.

## Что можно сделать

- **Сообщить об ошибке** — шаблон «Ошибка» в Issues.
- **Команда ведёт себя не как в Linux** — шаблон «Команда ведёт себя не как в Linux». Приложите вывод с настоящей машины, лучше всего с ALT.
- **Предложить уровень** — шаблон «Предложить уровень» или сразу pull request: как это сделать, описано в [docs/ADDING_LEVELS.md](docs/ADDING_LEVELS.md).
- **Поправить текст** — задания лежат в `src/levels/*.js`, строки интерфейса и справки `man` — в `src/i18n/ru.js`.

## Правила для кода

- Без внешних зависимостей. Игра должна собираться в один файл и открываться без сети.
- Имена верхнего уровня во всех модулях уникальны: сборка склеивает модули в одну область видимости. `npm run check` скажет, если что-то совпало.
- Логика (`src/core`, `src/commands`, `src/netsim`, `src/levels`) не трогает DOM. Всё, что видит игрок, идёт через `print`, `ask` и `IO` из `src/core/io.js`. Благодаря этому логика тестируется в Node.
- Системные сообщения команд пишутся по-английски, как в настоящем Linux. Наши подсказки — по-русски, через поле `note` и `T` из `src/i18n/ru.js`.
- Форматирование: `npx prettier --write .` (настройки в `.prettierrc.json`).

## Правила для уровней

- Один уровень учит одной вещи.
- Всё, что нужно для решения, объяснено на предыдущих уровнях. Если нет — сначала нужен уровень, который это объясняет.
- У уровня есть эталонное решение (`solve`): тесты проверяют, что уровень проходим.
- Подсказка даёт готовую команду. Задание объясняет, *почему* она работает.
- Сетевые уровни ориентированы на ALT Linux: etcnet, `/etc/net/sysctl.conf`, `/etc/sysconfig/iptables`.

## Перед pull request

```sh
npm test
npm run build
```

Изменения интерфейса проверьте в светлой и тёмной теме и на узком экране (около 400 px).

## Поведение

Будьте вежливы и терпеливы: многие здесь только учатся, и это нормально. Подробнее — [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
